### 🌟 About Project
CareVoice is a complete healthcare management system where patients can upload medical reports, AI analyzes symptoms, and doctors can manage appointments. Built for AP hospitals with Telugu + English support.

### ✨ Key Features
- 👨‍⚕️ Doctor & Patient Dashboards
- 📄 Medical Report Upload & Storage
- 🤖 AI Symptom Checker
- 📊 Professional Admin Panel
- 🔒 Secure Authentication
- 💾 MySQL / H2 Database Support

### 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot, Spring Security
- **Frontend:** HTML5, CSS3, Bootstrap, Thymeleaf
- **Database:** MySQL / H2
- **Tools:** Maven, Git, GitHub
